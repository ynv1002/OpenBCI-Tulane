# Colab Notebooks

These notebooks are the professor-facing interactive analysis layer for the final project. Each one is designed to run in Google Colab using uploaded files rather than hard-coded local paths.

## Current Notebook Set

1. `OpenBCI_Signal_Explorer.ipynb`
   - Raw-signal inspection, preprocessing, channel review, filtering, and marker inspection.

2. `Jaw_Click_Decoder.ipynb`
   - Jaw clench preprocessing, feature extraction, model comparison, and click-trigger replay.

3. `EEG_Left_vs_Right_Benchmark.ipynb`
   - Honest LEFT vs RIGHT benchmarking with both windowed and event-based analyses.

4. `Hybrid_BCI_Controller.ipynb`
   - Final hybrid runtime interpretation using uploaded live-run logs, metadata, and optional raw recordings.

## Usage Notes

- Upload the requested files directly into Colab when each notebook prompts for them.
- The notebooks are intended to complement the static write-up in `/report` and `/results`.
- The notebook content is still under active refinement, but the overall four-notebook structure is now in place.
