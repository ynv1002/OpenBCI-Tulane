# Legacy Experiments

This folder contains older, more isolated experiments from the earlier EMG-focused phase of the project.

Current subfolders:

- `openbci_emg_lr_baseline/`
- `openbci_emg_processing_audit/`
- `openbci_emg_replay_gui/`

## How To Treat These

Keep them as historical reference and comparison points.

Do not treat them as the active path for the current BCI project unless a prompt explicitly asks for:

- the older `Y_EMG.csv` workflow
- OpenBCI-style EMG joystick logic
- replay of the older EMG baseline outputs

For the active EEG/jaw control direction, use `analysis/` instead.
