# Live Run Examples

This folder holds the example run bundles for the hybrid tracking-game system.

Professor-facing live examples:

- `20260415_103538_live_cyton_Testing-1`
- `20260415_103646_live_cyton_Testing-2`
- `20260415_104152_live_cyton_3`

Additional replay smoke-test bundles may also appear here because the current runtime logs new runs into this same folder by default.

Each run currently includes:

- `run_metadata.json`
- `classifier_provenance.json`
- `adaptation_summary.json`
- `phase_log.csv`
- `protocol_truth.csv`
- `marker_log.csv`
- `control_trace.csv`
- `control_events.csv`
- `game_trace.csv`
- `game_events.csv`
- `session_feedback.json`
